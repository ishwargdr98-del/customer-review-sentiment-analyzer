Customer Review Sentiment Analyzer

Project Overview

This project uses machine learning and natural language processing to classify customer reviews as positive or negative.

Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression

How It Works

1. Load customer review text.
2. Convert text into numerical features using TF-IDF.
3. Train a Logistic Regression classifier.
4. Predict whether a review is positive or negative.

Learning Objectives

- Understand text preprocessing.
- Learn TF-IDF feature extraction.
- Practice machine learning classification.
